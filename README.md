# 🛍️ ShopEase - E-Commerce Website

A simple **E-Commerce website built with React** where users can browse products, search and filter products, view product details, manage their cart, and place orders.

## 🚀 Features

- 🏠 Home page with Hero Slider
- 🔍 Search products
- 🏷️ Filter products by category
- 📦 Product details
- 🛒 Add products to cart
- ➕ Increase/decrease quantity
- ❌ Remove products from cart
- 💳 Checkout page
- ✅ Order placed page
- 👤 Profile page
- 🧭 React Router navigation
- 🌐 Cart management using Context API

## 🛠️ Technologies

- React.js
- React Router
- Context API
- JavaScript
- HTML
- CSS
